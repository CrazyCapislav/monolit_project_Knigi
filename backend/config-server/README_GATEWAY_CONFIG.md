# Конфигурация Gateway

Конфигурация Gateway была вынесена в Config Server для централизованного управления.

## Что нужно сделать

1. Скопируйте файл `gateway.yml.example` в ваш git репозиторий конфигураций:
   - Репозиторий: https://github.com/CrazyCapislav/configRepo
   - Файл должен называться: `gateway.yml`

2. Обновите конфигурацию в репозитории согласно вашим требованиям

3. Gateway автоматически подтянет конфигурацию из Config Server при запуске

## Структура конфигурации

Файл `gateway.yml` содержит:
- Настройки портов (через переменные окружения)
- Маршрутизацию к микросервисам
- CORS настройки
- Swagger UI конфигурацию
- Eureka настройки
- Management endpoints

## Локальная разработка

Для локальной разработки без Config Server, Gateway будет использовать минимальную конфигурацию из `application.yml`.
